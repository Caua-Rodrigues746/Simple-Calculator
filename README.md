# Simple Calculator

A simple Python Calculator that allows the user to perform basic math operations.

## Version 1

### Features

- Addition
- Subtraction
- Multiplication
- Division
- Basic input error handling

### What I Learned

- Variables
- input()
- int() and float()
- if / elif / else
- try / except

---

## Version 2

Version 2 expands on the original Simple Calculator by allowing the user to perform operations with multiple numbers.

### Features

- Addition
- Subtraction
- Multiplication
- Division
- Basic input error handling
- Allows the user add any number of numbers to an operation

### What I Learned

- While loops
- If statements
- Nested if statements
- User input
- Error handling
- Break
- F-strings
- List indexing
- String methods
- List slicing
